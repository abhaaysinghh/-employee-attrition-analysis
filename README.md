
# Employee Attrition & Workforce Analytics System

## Project Overview

A Python-based HR analytics application designed
to analyse employee attrition patterns and support
workforce retention decisions.

## Technologies

- Python
- Pandas
- NumPy
- Streamlit
- Plotly
- Matplotlib
- Seaborn

## Main Features

1. Employee data upload
2. Data cleaning and validation
3. Workforce KPI dashboard
4. Salary analysis
5. Overtime analysis
6. Job satisfaction analysis
7. Tenure analysis
8. Department-wise attrition
9. HR recommendations
10. Data export

## Installation

Install the dependencies:

pip install -r requirements.txt

## Run the application

streamlit run app.py

## Data

The included employee dataset is synthetic
and is intended for demonstration and testing.

## Disclaimer

Analytical associations do not establish causation.
HR recommendations should be reviewed by qualified
decision-makers.
